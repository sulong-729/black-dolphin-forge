Requires Node.js 22.16+. macOS package is unsigned and not notarized. Runtime upgrade/service and skill download tested on macOS; macOS Installer GUI and actual Windows installation have not been tested. Windows is a ZIP/CMD installer, not an MSI/EXE.

Application source: [main branch](https://github.com/sulong-729/black-dolphin-forge/tree/main), commit `6998b99`.

Creator adapters are automatically selected from project metadata. 3.6.3 Editor/build and 2.4.15 Editor reads passed on macOS. Creator 2.x builds remain experimental; 2.4.15 export failed in the tested Creator worker, and Creator 2.1.3 is not installed for real testing. See the [version matrix](https://github.com/sulong-729/black-dolphin-forge/blob/main/docs/compatibility.md).
